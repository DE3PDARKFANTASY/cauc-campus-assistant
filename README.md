一款为中国民航大学在校生打造的**第三方、开源、无广告**校园助手 App。课程表、考试、空教室、校园网、宿舍电费、校园卡，一站式搞定；账号密码只存在你自己的手机里。

> 本项目为**独立开发**的第三方工具：与中国民航大学及其信息化部门、教务系统厂商**无任何隶属、合作或授权关系**，亦不包含、不反编译任何第三方小程序或 App 的代码与资源。所有数据均来自学校官方系统中**你本人有权访问的页面**，App 只是帮你把它们看得更方便。

---

## ✨ 特性亮点

- **无广告、无追踪、不上传**：不接任何统计 / 广告 SDK，不向任何服务器上传你的数据
- **凭据不出本机**：账号密码仅保存在本机（非明文存储），可在设置中一键清除
- **内外网自适应**：在校内走校园网直连，在校外自动经学校 WebVPN 通道，切换网络自动恢复，被顶号后自动重登
- **打开即用**：课表等常用数据本地缓存，冷启动秒出，后台静默刷新
- **一切可定制**：首页卡片显示与排序、每类数据的缓存时长（秒到年任意组合）、真实 / 演示数据源一键切换

## 📱 功能总览

### 学习教务

| 功能 | 说明 |
|---|---|
| 📅 周课表 | 按周查看课程，左右滑动切换周次，今天与当前周高亮；点课程看详情（起止时间、教师、教室、周次范围） |
| 📚 总课表 | 整学期全部课程一览，含学分、教师、教室与周次 |
| 📄 课表 PDF 导出 | 一键调用学校官方课表导出，PDF 自动保存到系统「Download」文件夹 |
| 📝 考试安排 | 考试时间、地点、座位号，考前一目了然 |
| 🚪 空教室查询 | 学校真实空闲教室数据：东丽 / 宁河双校区；周次、星期、节次**多选**（支持全选 / 清空）；可按楼号、教室类别、名称编号、座位数区间进一步筛选；查询条件自动记忆 |
| 🎓 绩点学业 | 平均绩点、学分进度、课程修读统计（数据来自学校「学业情况」页） |

### 校园生活

| 功能 | 说明 |
|---|---|
| ⚡ 宿舍电费 | 东丽校区照明 / 空调分表查询；宁河校区账户余额查询；两校区并列一键切换；充值跳转学校官方渠道完成 |
| 🗺️ 校园地图 | 规划中：正在寻找南苑 / 北苑高清地图原图，欢迎通过 Issue 提供 |
| 💳 校园卡 | 实时余额、本月收支统计、近期消费流水；支持**一键挂失**、捡获卡招领入口 |

### 校园网

| 功能 | 说明 |
|---|---|
| 🔐 一键认证 | 校园网一键登录 / 注销，认证状态实时显示 |
| 📶 在线设备 | 查看账号下所有在线设备（IP / MAC / 主机名 / 终端类型 / 在线时长），支持**将指定设备强制下线** |
| 🕐 上网记录 | 按日期范围查询历史上网记录（起止时间、时长、流量、IP），支持「今天 / 近 7 天 / 近 30 天」快捷筛选 |

### 个性化与设置

| 功能 | 说明 |
|---|---|
| 🧩 首页卡片自定义 | 每张信息卡的显示 / 隐藏 / 排序随心配 |
| 🧰 常用服务自定义 | 服务九宫格入口自由增删 |
| ⏱️ 缓存时长自定义 | 课表、个人信息、考试、设备、电费等逐类设置缓存时间，从 **1 秒到 1 年**任意组合（0 = 实时） |
| 🎭 数据源切换 | 真实系统 / 演示数据一键切换，方便体验与截图 |
| 🌙 深色模式 | 跟随系统或手动开关，全部页面适配 |

## 📥 下载安装

- **Release**（推荐）：前往 [Releases](https://github.com/DE3PDARKFANTASY/cauc-campus-app/releases) 下载最新 APK，安装即用（要求 Android 7.0 及以上）
- **自行构建**：克隆本仓库，用 Android Studio 打开 `android/` 目录构建

> 首次使用需要你的**学号 + 统一身份认证密码**。密码仅用于登录学校系统，只保存在本机；你也可以选择不保存，每次手动输入。

## ⚠️ 使用前必读

1. 本 App 的所有数据都来自学校官方系统**你本人有权访问的页面**，请合理安排查询频率，勿滥用。
2. **⚠️ 安全提示：许多学校系统仍使用 HTTP 明文协议传输数据**（学校信息化现状，与本 App 无关，本 App 无法改变服务端的协议）。这意味着你与学校系统之间的通信内容在传输路径上可能被第三方截获。**强烈建议在安全、可信的网络环境下使用**（如个人移动数据或可信的私人 Wi-Fi），避免在公共 Wi-Fi、来路不明的热点等不可信网络中查询课表、电费、校园卡等敏感信息。
3. 学期初 / 系统维护期间，学校系统本身可能不稳定，此时 App 内数据可能延迟或暂时不可用。
4. 电费充值等一切支付**均在学校官方渠道完成**，本 App 只负责把页面带到你面前，不代收、不代付、不经手任何资金。
5. 登录涉及学校统一身份认证，若学校端启用验证码等风控措施，请按页面提示完成。

## 🔐 隐私与数据

- 账号与密码：仅保存在本机（非明文存储），**不发送给开发者或任何第三方**；可在「我的 → 已保存账密」一键清除
- 缓存数据：课表、学籍、设备列表等查询结果仅保存在本机用于加速显示；缓存时长可在「我的 → 缓存时长」逐类调整或清零
- 网络行为：App 只向你本人登录的学校官方系统发起请求（外网可达性探测除外，不含任何个人数据）；**请注意传输安全**——如上所述，部分学校系统为 HTTP 明文协议，请尽量在可信网络中使用
- 卸载 App 即删除上述全部本地数据
